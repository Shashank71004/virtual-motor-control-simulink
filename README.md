# virtual-motor-control-simulink
Virtual motor speed control system developed using MATLAB and Simulink with PID and PWM-based control.
## Overview

This project presents a virtual motor control system developed using MATLAB and Simulink.

The model demonstrates closed-loop motor speed control using feedback, PID control, saturation, and PWM generation.

## Software Used

- MATLAB
- Simulink

## Control System

The control system consists of:

- Reference speed input
- Error calculation
- PID controller
- Saturation
- PWM generation
- Motor model
- Speed feedback

## Project Files

| File | Description |
|---|---|
| `Virtual_Motor_Control.slx` | MATLAB/Simulink motor control model |
| `Virtual_Motor_Control_Report.pdf` | Project report and documentation |

## How to Run

1. Open MATLAB.
2. Open Simulink.
3. Open `Virtual_Motor_Control.slx`.
4. Run the simulation.
5. Observe the motor speed response and control signals.

## Applications

This type of control system is relevant to:

- Electric motor control
- Electric vehicles
- Industrial drives
- Power electronics
- Feedback control systems
